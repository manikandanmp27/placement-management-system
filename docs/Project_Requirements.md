# Campus Placement Management System

## Project Overview

A web-based system to manage the college campus placement process.

The system allows students to view job opportunities, check eligibility, apply for jobs, and track their applications and interviews.

Placement officers can manage students, companies, jobs, applications, interviews, and placements.

## Main Features

### Student
- Register/Login
- View and update profile
- View available jobs
- Check eligibility
- Apply for jobs
- View application status
- View interview status
- View placement details

### Placement Officer/Admin
- Manage students
- Manage companies
- Manage jobs
- Set job eligibility criteria
- View and manage applications
- Manage interviews
- Manage placements
- View placement statistics

## Database

Main tables:

- Department
- Student
- Company
- Job
- Application
- Interview
- Placement

## Tech Stack

- Frontend: React
- Backend: Java + Spring Boot
- Database: MySQL
- API: REST API
- Version Control: Git + GitHub

## Main Workflow

Company → Job → Eligibility Check → Application → Interview → Selection → Placement

## Project Goal

Build a complete placement management system while learning:

- MySQL and SQL
- Database design
- Java backend development
- Spring Boot
- REST APIs
- React
- Git and GitHub
